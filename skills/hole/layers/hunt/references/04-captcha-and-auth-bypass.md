# 验证码对抗与认证绕过

> 适用前提：**自有靶场 / 授权项目 / 厂商提供的测试账号环境**。对未授权目标不做任何自动化尝试。

## 一、先判验证码类型（决定成本）

| 类型 | 特征 | 自动化难度 |
|---|---|---|
| 4 位数字/字母，无干扰线 | 字体固定、仅旋转+变色（本次实战就是这种） | 极低，人工 79%，打码 95%+ |
| 4-6 位带干扰线/噪点 | 有线条、点噪声 | 中，需 CNN 训练或打码 |
| 算术/中文 | `3+5=?`、汉字点选 | 中高，打码平台支持 |
| 滑动/点选（Geetest、极验、腾讯） | 缺口拼图、语序点选 | 高，不建议硬碰；优先找**服务端是否真的校验** |
| 无验证码 | — | 直接测锁定 |

**关键判断**：滑动验证码常出现在前端，但**服务端是否校验**才是漏洞点。裸打发送接口（不带 token）→ 若返回「验证失败」说明服务端校验到位，此路不通；若返回成功则是严重缺陷。

## 二、批量取码 + 拼图 + 一次识别（最高效手法）

思路：验证码一次性、绑定 session，逐张调 OCR 效率低。改为**开 N 个会话、各取一张、拼成一张大图、一次读完**，然后按序投递。

```powershell
# 1) 建 N 个会话，各自取码存 png（curl 带 Cookie）
# 2) 拼图
Add-Type -AssemblyName System.Drawing
$w=200; $h=62
$bmp = New-Object System.Drawing.Bitmap(($w*2), ($h*6))
$g = [System.Drawing.Graphics]::FromImage($bmp); $g.Clear([System.Drawing.Color]::White)
for($i=0; $i -lt 12; $i++){
  $img = [System.Drawing.Image]::FromFile((Resolve-Path ("c_" + ($i+1) + ".png")).Path)
  $g.DrawImage($img, (($i % 2)*$w), ([math]::Floor($i/2)*$h), $w, $h); $img.Dispose()
}
$g.Dispose(); $bmp.Save((Join-Path (Get-Location) "cap12.png"), [System.Drawing.Imaging.ImageFormat]::Png)
```

3) 用 `read_image` 一次读 12 张 → 按「左到右、上到下」格子顺序回填 → 一轮投 12 个请求。
4) **会话与验证码必须严格对齐**：第 i 个 cookie 配第 i 张码，错位率 = 失败率。
5) 批量脚本见 `scripts/captcha-montage.ps1`。

## 三、OCR 选型

| 方案 | 准确率 | 成本 | 说明 |
|---|---|---|---|
| 人工拼图识别 | 75-85% | 0 | 单人可维护 1-2 轮/分钟，适合一次性验证 |
| 打码平台 API | 92-97% | 几分钱/张 | 通用 4 位码；返回纯字符串，接入 10 行代码 |
| ddddocr（开源） | 85-93% | 0 | 本地部署，`pip install ddddocr`，对无干扰线验证码效果好 |
| 自训 CNN | 95%+ | 需 2-5k 标注 | 用拼图法先标注，再训练；只在长期项目值得 |

## 四、读报错反推服务端逻辑（最值钱的技巧）

把「字段留空」当作探针，观察服务端校验顺序：
```
验证码留空     → 「验证码不能为空」   ⇒ 该字段必填，且在密码前校验
二次验证留空   → 「账号或密码错误」   ⇒ 该字段非必填（或仅绑定后才校验）
两者都留空     → 看先报哪个       ⇒ 得到真实校验顺序
```
结论写法：`参数 X 留空不触发必填校验，服务端直接进入下一校验环节`。
**不要写**「已绕过 2FA」——除非你真的用某账号验证过。

## 五、其它认证绕过手法

- **参数污染**：`a=1&a=2`、`a[]=1`、大小写（`UserName` vs `username`）、`user.name` 与 `user[name]` 混用，看哪层取值不一致。
- **类型混淆**：`id=1` → `id[]=1`、`id={"$ne":null}`（NoSQL）、`id=1e1`、`id=01`。
- **路径/大小写**：`/admin` vs `/Admin`、`/admin/` vs `/admin/.`、`/admin%00`、`;/admin`。
- **方法切换**：GET 被拦但 POST/PUT/HEAD/OPTIONS 放行。
- **会话固定**：登录前固定 `PHPSESSID`，登录后用同一 ID 是否仍有效。
- **JWT**：`alg:none`、删签名段、弱密钥爆破（hashcat -m 16500）、`kid` 路径穿越、`jku` 指向自建 JWKS。

## 六、代理与速率（授权项目内）

- 速率：默认 ≤ 2 req/s，按项目约定；出现 429 立即降速而非换 IP。
- 代理池只在**授权明确允许**时使用；多数平台禁止用代理规避封禁。
- 每次请求记录 `时间/目标/参数/响应码/响应摘要`，便于复现与自证合规。
