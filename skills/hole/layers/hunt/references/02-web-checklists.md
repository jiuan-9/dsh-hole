## 1. 认证与会话

### 1.1 无失败锁定 / 可撞库
- 探针：固定账号错口令连打 20 次，记录 `状态码 / 响应体 / 耗时`；观察是否出现 429、账号锁定、验证码升级、IP 封禁。
- 判据：20 次后仍返回「账号或密码错误」且无任何阻断 = 无频控。
- 误报陷阱：验证码一次性时，大部分请求会停在「验证码错误」，**这类请求不算有效尝试**，必须统计「进入凭据校验」的次数。
- 修复：账号+IP 双维度计数、失败 N 次升级验证码、锁定并告警。

### 1.2 必填字段可省略（2FA / 验证码绕过）
- 探针：把二次验证字段（`auth_key`/`otp`/`smscode`/`token`）**留空提交**，与「验证码留空」做对照。
- 判据（读报错优先级反推逻辑）：
  | 返回 | 结论 |
  |---|---|
  | 「验证码不能为空」 | 服务端先判非空 → 该字段必填 |
  | 「验证码错误」 | 已比对 → 码错 |
  | 「账号或密码错误」 | **已越过该字段**，进入凭据校验 → 字段可省略 |
  | 无任何提示直接进下一步 | 校验完全缺失 |
- 误报陷阱：服务端可能「仅当账号绑定了 2FA 才校验」，留空通过不代表所有账号都能绕过。报告里写成「参数留空不触发必填校验」，别写成「已绕过 2FA」。
- 修复：必填字段强制非空；校验失败与密码失败分开计数。

### 1.3 用户枚举
- 探针：注册/找回/登录三处的「账号是否存在」接口，用存在与不存在的账号各打 3 次比对响应体与耗时。
- 判据：文案差异（「该号码可以使用」vs「已被注册」）、状态码差异、响应时间差 > 200ms。
- 修复：统一模糊文案 + 恒定响应时间。

### 1.4 密码重置逻辑
- 探针：找回密码全流程走一遍，重点看 ①重置链接/token 是否可预测（md5(email)、时间戳）②token 是否与会话绑定 ③改包替换手机号/邮箱/用户 ID 后能否对他人生效 ④token 是否一次性、有无过期 ⑤Host 头是否参与链接拼接（密码重置中毒）。
- 判据：改包后对**另一账号**生效 = 任意账号接管（高危）。
- 误报陷阱：只改了 `email` 参数但服务端从会话取用户 → 无效，别急着报。必须验证「目标账号确实被改」。

### 1.5 会话与 JWT
- Cookie 属性：`HttpOnly` / `Secure` / `SameSite` 是否缺失（单独报多为低危）。
- 会话固定：登录前后 `PHPSESSID` 是否变化；不变则存在固定攻击面。
- JWT：`alg:none` 接受、弱密钥（hashcat -m 16500）、`kid` 注入、`jku/x5u` 外链、claims 越权（改 `role`/`uid`）。

## 2. 授权（越权 / IDOR）

- 探针矩阵：同一请求换 **水平身份**（A 用户 token 读 B 用户资源）、换 **垂直身份**（普通用户打管理接口）、**去掉鉴权头**直连、**改 ID 类型**（数字→数组/对象）、**改 HTTP 方法**（GET→POST/PUT）。
- 判据：返回 200 且含他人数据。**读 1 条即停**，不要遍历。
- 误报陷阱：
  1. 双因子绑定（邮箱+订单号）的查询接口，改单号一律「不存在」→ 不可利用，早收手；
  2. 返回 200 但内容是空列表/占位 → 不是越权；
  3. 前端隐藏了按钮但接口无校验 → 这才是真越权，务必直接打接口而不是点页面。
- 高危落点：订单详情/导出/打印/合同 PDF/发票、会员资料、消息中心、审批流。

## 3. 注入

### 3.1 SQL 注入
- 探针顺序：`'` → `and 1=1` / `and 1=2` → `order by N` → `sleep(3)` → OOB（DNS 外带）。
- **长度抖动的坑**：页面含时间戳/推荐位/随机广告时长度差 ±100 属噪声，不能当布尔差异。**以时间盲注为准**（基线 70ms vs 命中 3000ms 一目了然）。
- 数字位注入常见于 `/news/123.htm`、`/line/1009.htm` 这类伪静态路径。
- 二次注入：注册/留言写入 → 后台列表读取处触发，需账号。
- 判据：稳定复现 3 次的时间差或数据差异。

### 3.2 命令注入 / 代码执行
- 探针：`;id`、`|id`、`` `id` ``、`$(id)`、`%0aid`；无回显时用 `sleep 5` 或 DNS 外带（OAST）。
- 常见入口：图片处理（imagemagick）、PDF 导出、备份/导入、ping/telnet 诊断、模板渲染。

### 3.3 SSTI / 表达式注入
- 探针：`{{7*7}}`、`${7*7}`、`#{7*7}`、`<%= 7*7 %>`、`*{7*7}`；命中返回 49。
- 语言判定后走对应利用链（Jinja2/Twig/Freemarker/Velocity/SpEL/OGNL）。

### 3.4 XXE / SSRF / 反序列化
- XXE：任何收 XML 的接口（SOAP、导入、SAML、docx/xlsx 上传解析）→ 外部实体读 `/etc/passwd` 或 OOB。
- SSRF：所有 URL 参数（`url=`、`image=`、`callback=`、`webhook=`、`proxy=`）→ `http://127.0.0.1:PORT`、`file:///etc/passwd`、`gopher://`、云元数据 `http://169.254.169.254/latest/meta-data/`，DNS 回连验证。
- 反序列化：Java（`rO0AB`/`aced0005`）、PHP（`O:`）、.NET（`AAEAAAD`）、Python pickle；有已知 gadget 时用 ysoserial 系列，仅验证 DNS 回连，不执行破坏性命令。

## 4. 文件类

### 4.1 上传
- 绕过矩阵：双扩展名（`shell.php.jpg`）、`.phtml/.pht/.php5/.jspx`、`Content-Type` 伪造、大小写（`.PhP`）、`%00` 截断（老版本）、`.htaccess` 覆盖、图片马 + 解析漏洞、zip/tar 解压穿越。
- 判据：能访问且被解析执行。**只上传打印内容的无害文件并立即删除**。
- 注意：全站 `*.php` 统一 403 的站点，上传点难以直接解析，优先找「解析规则例外」目录。

### 4.2 路径穿越 / 任意文件读取
- 探针编码变体：`../`、`%2e%2e%2f`、`..%2f`、`%252e%252e%252f`、`....//`、`..\`、绝对路径、`/proc/self/environ`。
- 常见参数：`file=`、`path=`、`download=`、`template=`、`lang=`、`img=`。

### 4.3 文件包含（LFI）
- 探针：`?page=../../../../etc/passwd`、`php://filter/convert.base64-encode/resource=index`、`data://`、日志投毒 `/var/log/nginx/access.log`。

## 5. 业务逻辑

- 金额/数量篡改：改成 `0`、`-1`、`0.01`、超大值；观察服务端是否二次校验。
- 优惠券/积分：重复使用、并发领取（并发 10 线程）、条件绕过（改商品 ID 到低价品类）。
- 状态机跳跃：跳过支付直接调「支付成功回调」、跳过审核直接发布。
- 并发超卖：库存 1 件并发下单 10 次，看是否成功多个。
- 判据：服务端产生的实际业务影响（订单生成、余额变化），不是前端提示。

## 6. 前端

- XSS 上下文矩阵：HTML 正文、属性内、`<script>` 内、`javascript:`、CSS、JSON 回显。每处 payload 不同；先看转义（`&lt;` = 已实体化）。
- DOM XSS：`location.hash`、`innerHTML`、`document.write`、`eval`。
- postMessage：`*` 目标源 + 无 origin 校验 → 可被任意页注入。
- CSP 缺失单独报多为低危，但若存在 XSS 则可放大危害。

## 7. 基础设施

- **403/401 绕过 header 矩阵**：`X-Forwarded-For: 127.0.0.1`、`X-Real-IP`、`Client-IP`、`X-Originating-IP`、`X-Forwarded-Host`、`X-Remote-Addr`；再加路径混淆 `//admin`、`/./admin`、`/admin%20`、`/admin/..;/`。
- 先测 `/favicon.ico`：连静态都 403 = 整站 IP 白名单，直接换目标。
- Host 头：改 Host 后看是否回显到页面/邮件链接（密码重置中毒）。
- CORS：`Origin: https://evil.example.com`，看 `ACAO` 是否回显 + `ACAC:true`。
- 子域接管：CNAME 指向已下线服务（GitHub Pages、S3、Heroku、Unbounce、Fastly），且该主机返回该服务的「未配置」页面。
- 缓存投毒/请求走私：仅在授权明确允许时做，且不做 DoS 性质验证。

## 8. 通用误报清单（提交前必过）

| 现象 | 为什么不是漏洞 |
|---|---|
| 页面长度差 ±100 | 时间戳/推荐位噪声 |
| `*.php.bak` 返回原文件内容 | PATH_INFO 复用，不是备份泄露 |
| 上传成功但访问 403 | 未解析，不构成 RCE |
| 越权接口返回 200 空数组 | 可能已做数据级过滤 |
| 响应头缺 X-Frame-Options | 低危，需配可点击的敏感操作才有意义 |
| 验证码可识别 | 单独不构成漏洞，必须配合无锁定/可撞库才有意义 |
| 目录列表 403 | 是防护生效，不是漏洞 |
## 8. 供应链（A03:2025 · 新增）

- 探针：`/package.json` `/composer.lock` `/yarn.lock` `/go.mod` 是否可直接访问；前端 JS 里是否出现已知脆弱库版本（jQuery 1.x、layui 旧版、`swiper 3.x`）。
- 第三方组件版本 → 查已知 CVE（如 jQuery < 3.5 的 XSS、Struts2、Fastjson）。
- CDN/对象存储：`<script src="//cdn.xxx">` 若指向可接管的桶或已过期域名 → 供应链投毒面。
- 判据：**能读到依赖清单且含已知漏洞版本**才算；只暴露版本号不构成。
- 修复：锁文件移出 Web 根、前端依赖 SRI（Subresource Integrity）、组件 SCA 扫描入 CI。

## 9. 弱加密（A04:2025）

- 探针：登录/支付请求是否 HTTPS；Cookie 是否 `Secure`；密码哈希是否可嗅探（响应中返回 `md5(...)`）；JWT 是否用 `HS256` 且密钥可猜；加密参数是否可预测（AES-ECB 块重复）。
- 判据：能还原明文或预测密文。**只报告可实际利用的**，缺 HSTS 单独报多为低危。

## 10. 日志与告警缺失（A09:2025）

- 探针：连续 20 次登录失败后，观察是否出现锁定/告警；对同一接口发起异常请求，看是否被限流。
- 判据：**无任何阻断与告警** = A09 缺陷。这条常被忽略，但在 2025 版是独立风险类别。
- 写法：与认证缺陷合并描述（无锁定 = 既是 A07 也是 A09），评级时可作为加分理由。

## 11. 异常处理（A10:2025 · 新增）

- 探针：畸形参数（数组代替字符串）、超大值、空字节、非法编码、缺字段；观察是否回显堆栈、SQL 语句、绝对路径、框架版本。
- 判据：出现 `Stack trace` / `SQLSTATE` / `at com.xxx` / 绝对路径 = 信息泄露（联动 A02）。
- 反向利用：报错差异可用于做**逻辑推断**（见 `04` 第五节「读报错反推」）。

## 12. API 与 WebAssembly（WSTG 4.12 / 4.13）

### 12.1 API 专项
- 探针：`/swagger-ui.html` `/v2/api-docs` `/openapi.json` `/graphql`；未授权直连每个端点；改 `HTTP 方法`（GET→POST/PUT/DELETE）；批量赋值（`{"role":"admin"}`）；分页参数放大（`limit=99999`）。
- 判据：**接口返回数据但无身份校验** = 未授权访问（A01）；能改自己不该改的字段 = 批量赋值。
- 误报陷阱：返回 401/403 是防护生效；返回 200 但空数组不代表越权。

### 12.2 GraphQL
- 探针：`/graphql?query={__schema{types{name}}}` 自省是否开启；单请求嵌套查询测深度限制。
- 判据：自省开启 + 无鉴权 → 可枚举全部字段与变更操作。

### 12.3 WebAssembly（简述）
- 探针：`.wasm` 是否可直接下载；是否内含密钥/接口地址（`strings web.wasm | grep -i api`）。
- 判据：wasm 内含硬编码凭证或内部地址 → 信息泄露。

## 13. 评级参考（引用标准，不自己发明）

| 发现 | 建议等级 | 依据 |
|---|---|---|
| 未授权访问后台接口并取数 | 高危 | OWASP A01 + CWE-639 |
| 遗留调试文件泄露路径/内网地址 | 中危 | CWE-200 / CWE-489 |
| 登录无锁定 + 2FA 可空 | 中危（争取高危） | CWE-307 / CWE-287 |
| 反射型 XSS（需交互） | 低-中 | CWE-79 |
| 缺安全响应头 | 低危 | CWE-693 |
